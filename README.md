# VERTO-RIDE-Vehicle-Renting-Website
VERTORIDE makes vehicle renting simple, affordable, and hassle-free. Choose your preferred vehicle, select pickup and return dates, and book with ease. Your journey, your choice, our responsibility!

This project has been developed as part of Continuous Assessment 2 (CA2) for the course CSE326 – Internet Programming. The website is built using HTML, CSS, and basic JavaScript.
